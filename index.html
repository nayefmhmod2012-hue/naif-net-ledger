⚙️ إعدادات السحابة وتيليجرام والتعليمات

كود Google Apps Script الجاهز (انسخه والصقه في Extensions > Apps Script): 
function getOrCreateSheet() {
  var fileName = "حسابات شبكة نائف نت";
  var files = DriveApp.getFilesByName(fileName);
  var ss;
  if (files.hasNext()) {
    ss = SpreadsheetApp.open(files.next());
  } else {
    ss = SpreadsheetApp.create(fileName);
  }
  var sheet = ss.getSheetByName("بيانات_الحسابات");
  if (!sheet) {
    sheet = ss.insertSheet("بيانات_الحسابات");
  }
  return sheet;
}

function doGet(e) {
  var sheet = getOrCreateSheet();
  
  // حفظ عبر GET
  if (e && e.parameter && e.parameter.save_data) {
    sheet.getRange(1, 1).setValue(e.parameter.save_data);
    return ContentService.createTextOutput(JSON.stringify({status: "ok"}))
      .setMimeType(ContentService.MimeType.JSON);
  }

  // قراءة الحسابات للمزامنة
  var data = sheet.getRange(1, 1).getValue();
  return ContentService.createTextOutput(data || "{}")
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = getOrCreateSheet();
  var rawData = "";
  
  if (e && e.postData && e.postData.contents) {
    rawData = e.postData.contents;
  } else if (e && e.parameter && e.parameter.data) {
    rawData = e.parameter.data;
  }
  
  if (rawData) {
    sheet.getRange(1, 1).setValue(rawData);
  }
  
  return ContentService.createTextOutput(JSON.stringify({status: "ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}
خطوات تفعيل السكربت والربط السحابي:
  1. نسخ الكود: اضغط على زر 📋 نسخ الكود كامل بالأعلى لنسخ كود Google Apps Script.
  2. فتح محرر السكربت: افتح حسابك في Google Drive أو أنشئ جدول بيانات جديد في Google Sheets، ثم من القائمة العلوية اختر Extensions ثم Apps Script.
  3. لصق وحفظ الكود: احذف أي كود افتراضي موجود داخل المحرر، والصق الكود الذي نسخته، ثم اضغط أيقونة الحفظ (Save).
  4. نشر السكربت كـ Web App: اضغط على زر Deploy في الأعلى ثم اختر New deployment، ومن أيقونة الترس بجانب Select type اختر Web app.
  5. ضبط الصلاحيات: في خانة Execute as اتركها Me، وفي خانة Who has access اختر Anyone، ثم اضغط Deploy ووافق على الأذونات.
  6. ربط الرابط بالنظام: انسخ رابط Web app URL الناتج، ثم اضغط في شريط النظام على زر ⚙️ إعدادات السحابة وتيليجرام والتعليمات والصق الرابط ليتم الربط والمزامنة تلقائياً (وسيُنشئ السكربت تلقائياً ملفاً باسم حسابات شبكة نائف نت وبداخله ورقة بيانات_الحسابات).
خطوات ربط البوت وإرسال النسخ الاحتياطية إلى تيليجرام:
  1. إنشاء البوت والحصول على التوكن: افتح تطبيق تيليجرام وابحث عن @BotFather، أرسل الأمر /newbot واتبع الخطوات لتسمية البوت وتحصل على Bot Token.
  2. تفعيل البوت والحصول على Chat ID: افتح البوت الذي أنشأته واضغط Start (بدء)، ثم افتح @userinfobot لنسخ رقم Id الخاص بحسابك (أو رقم القناة بعد إضافة البوت مشرفاً فيها).
  3. حفظ البيانات في النظام: من تبويب ⚙️ الإعدادات والربط أدخل التوكن ثم رقم الـ Chat ID واضغط 💾 حفظ الإعدادات.
  4. إرسال نسخة احتياطية: اضغط على زر 📤 نسخ تيليجرام لإرسال ملف JSON بجميع الحسابات مرفقاً بالتاريخ والوقت إلى دردشتك مباشرة.
